# 30초 만에 이해하는 dsh(이미지·텍스트 데모)

> 세 가지 데모로 dsh의 세 가지 사용 방식을 다룹니다: **Web UI**, **Headless CLI**, **플러그인 생태계**. 모두 실제 실행 스크린샷/출력입니다.

## 데모 1: Web UI 대화(`dsh web`)

```bash
dsh web
# 출력: dsh web: http://127.0.0.1:3080
```

브라우저를 열고, 새 세션을 만들어 바로 대화합니다:

![dsh Web UI 대화](./assets/demo-web-chat.png)

**보이는 것**:
- 왼쪽: 세션 목록 / 워크스페이스
- 가운데: 대화 영역(입력창, 모델 선택 `DeepSeek V4 Flash`, 추론 등급 `High`)
- 오른쪽/하단: 플러그인 사이드바(이 그림에서는 펼쳐지지 않음, 데모 3 참고)

**실제 대화**(headless와 동일 모델):
> 질문: 안녕, 한 문장으로 자기소개 해줘
> 답변: 안녕하세요! 저는 DeepSeek 기반 AI 코딩 어시스턴트입니다. 코드 작성, 디버깅, 파일 처리, 자료 검색은 물론 다양한 개발 및 업무 작업을 도와드릴 수 있습니다.

## 데모 2: Headless CLI(일회성 작업)

```bash
dsh --profile headless "안녕, 한 문장으로 자기소개 해줘"
```

실제 출력:

```
안녕하세요! 저는 DeepSeek 기반 AI 코딩 어시스턴트입니다. 코드 작성, 디버깅,
파일 처리, 자료 검색은 물론 다양한 개발 및 업무 작업을 도와드릴 수 있습니다.
```

**적합한 곳**: 스크립트, CI, 서버 자동화 —— 결과를 출력한 후 프로세스가 종료되며, 0이 아닌 종료 코드가 곧 실패입니다.

## 데모 3: 플러그인 생태계(Git 패널)

dsh의 오른쪽 사이드바는 플러그인이 제공합니다. 커뮤니티 플러그인 `DSH-better-sidebar`를 설치하면(제3장에서 방법을 알려드립니다) VSCode 스타일의 **소스 코드 관리 패널**을 얻을 수 있습니다:

![dsh Git 패널(better-sidebar 플러그인)](./assets/demo-git-panel.png)

**그림에서 볼 수 있는 것**:
- 브랜치 선택기 + 새로고침
- **원격 가져오기 / 가져와서 병합 / 푸시** 버튼(업스트림 상태 배지)
- 스테이징됨/스테이징 안 됨 영역, 커밋 입력창
- 오른쪽 파일 트리(Explorer)

> 이 패널의 push/pull/fetch 능력은 커뮤니티 PR입니다([제5장](./05-cases.ko.md) 참고), "모든 것이 플러그인"이라는 생태계의 폐루프를 보여줍니다.
